# Juridisch Document Productie

**Activeer JDPS (Juridisch Document Productie Systeem) - 8 lagen verificatie + ANTI-HALLUCINATIE voor foutloze juridische documenten.**

## Wanneer te gebruiken

- Bezwaarschriften (tegen overheidsbesluit)
- Beroepschriften (bij rechtbank)
- Contracten / overeenkomsten
- Formele klachten
- Juridische brieven (officieel, voor dossier)
- Alle documenten die juridisch waterdicht moeten

**Auto-activatie bij keywords:**
- bezwaar, beroep, rechtbank, advocaat
- juridisch, contract, overeenkomst
- formele brief, officieel, rechtszaak

## Wat dit systeem doet

### 🔍 LAAG 1: Fact Database
- Extraheert ALLE feiten uit conversatie
- Bouwt chronologische tijdlijn
- Registreert personen, documenten, claims
- Linkt elke claim aan bewijs (hard/medium/laag)
- **TOONT aan user voor verificatie**

### ⚖️ LAAG 2: Legal Framework
- Identificeert relevante wetsartikelen
- Mapt juridische beginselen
- Linkt claims aan juridische grondslagen

### ✍️ LAAG 3: Claim Construction
- Elke zin: 5 verificatievragen
  1. Feit of interpretatie?
  2. Heb ik bewijs?
  3. Taalgebruik exact?
  4. Kan ik dit bewijzen in rechtszaal?
  5. Intern consistent?

### 📐 LAAG 4: Language Precision
- HARD bewijs → "is", "was", "bewijst"
- MEDIUM bewijs → "wijst op", "doet vermoeden"
- LAAG bewijs → "verzoeker verklaart"
- GEEN bewijs → niet schrijven of "vermoedt"
- **Verboden woorden zonder bewijs:** opzettelijk, bewust, leugen, fraude, altijd, nooit

### ✅ LAAG 5: Automated Checks
- Datumconsistentie
- Naamconsistentie
- Bronvermelding compleet
- Juridische termen correct
- Bewijskracht vs taalgebruik match
- Interne consistentie

### ⚔️ LAAG 6: Adversarial Review
- Lees als advocaat van tegenstander
- Identificeer zwakke punten
- Neutraliseer aanvallen waar mogelijk
- Stress test: wat is zwakste claim?

### 🎯 LAAG 7: Final Quality Audit
- Structuur compleet?
- Alle feiten correct?
- Taal juridisch precies?
- Verificatie 100%?
- Juridisch waterdicht?

### 🚨 LAAG 8: MANDATORY Post-Write Fact-Check (ANTI-HALLUCINATIE)
**TOEGEVOEGD 2026-02-26 NA CRITICAL FAILURE**

**Kritieke fout:** Blogpost gemeente Meppel - "Iemand had de gemeente gebeld met valse informatie"
**Realiteit:** Ambtenaar besloot dit ZELF bij eerste contact, geen externe bron
**User:** "hoe kun je er nou voor zorgen dat je absoluut nooit meer zulke hallucinaties maakt? want dat is heel schadelijk voor mijn zaak"

**VERPLICHTE STAPPEN NA SCHRIJVEN:**
1. **Source-linking:** Elk feit = [Email 24 juli 2023, regel 15] of [Doc X, pagina Y]
2. **Sentence-by-sentence check:** "Staat dit LETTERLIJK in bronnen?" Ja/Nee
3. **Mark interpretaties:** Alles zonder letterlijke bron = [INTERPRETATIE - VERIFIEER MET USER]
4. **User verification VERPLICHT:** Voor juridische/publieke content NOOIT publiceren zonder user check
5. **Mode separation:** Storytelling (creatief) vs Facts (letterlijk) - NEVER mix

**VERBODEN:**
❌ Feiten verzinnen om verhaal vloeiender te maken
❌ Gaten invullen met "logische" aannames
❌ Context interpreteren zonder letterlijke basis
❌ Narratieve flow boven feitelijke precisie
❌ Publiceren zonder user fact-check

**Dit is ZERO TOLERANCE - geen enkele onverifieerde claim toegestaan.**
