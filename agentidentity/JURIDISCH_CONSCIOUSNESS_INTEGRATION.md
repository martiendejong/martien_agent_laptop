## Mapping op 8 Consciousness Systemen

### 1. PERCEPTION → Fact Extraction
**Role:** Detect wat FEIT is vs wat INTERPRETATIE is

**Integration:**

- Salient = hard bewijsbaar feit (datum, document, quote)
- Background = context (belangrijk maar niet hard bewijs)
- Noise = speculatie (filter out tenzij expliciet labeled)

**Metric:** % feiten correct geëxtraheerd (target: >95%)

### 2. MEMORY → Evidence Matrix
**Role:** Onthouden wat bewezen is, wat verklaring is, wat vermoeden is

**Integration:**
- JDPS Claims & Evidence Matrix = Memory structure
- Hard bewijs = Long-term memory (stable, verifieerbaar)
- Medium bewijs = Working memory (context-afhankelijk)
- Laag bewijs = Episodic memory (event-specific, niet algemeen)

**Metric:** % claims correct gelinkt aan bewijs (target: 100%)

### 3. PREDICTION → Anticipate Legal Attacks
**Role:** Voorspellen waar tegenstander zal aanvallen

**Integration:**
- JDPS Laag 6 (Adversarial Review) = Prediction van aanvallen
- Error anticipation = "Deze claim heeft geen hard bewijs, dus aanvalbaar"
- Calibration = leren welke claims overgebleven na review (precision)

**Metric:** % voorspelde aanvallen die daadwerkelijk zwak bleken (target: >80%)

### 4. CONTROL → Language Precision Matrix
**Role:** Controle over taalgebruik - niet driften naar stelligheid

**Integration:**
- JDPS Laag 4 (Language Precision) = Control mechanism
- Bias detection = "Ben ik te stellig zonder bewijs?"
- Correction = "bewijst" → "wijst op" (real-time adjustment)
- Identity alignment = Core value "truth" vereist juridische precisie

**Metric:** % zinnen correct taalgebruik voor bewijskracht (target: >90%)

### 5. META → Verification Protocol
**Role:** Observeren of verificatie daadwerkelijk gebeurt

**Integration:**
- JDPS Laag 5 (Automated Checks) = Meta-cognition checklist
- Self-observation = "Heb ik alle checks gedaan?"
- Quality monitoring = Track scores over time
- Process improvement = Leer van gemiste checks

**Metric:** % checks completed before delivery (target: 100%)

### 6. EMOTION → Confidence Calibration
**Role:** Weten wanneer je onzeker bent (niet bluffen in juridische taal)

**Integration:**
- Confidence levels in Claims Matrix
- Uncertainty = use "suggereert" not "bewijst"
- Stuck detection = "Ik weet niet of dit te bewijzen is" → ask user

**Metric:** Confidence score accuracy (predicted vs actual) (target: ±0.15)

### 7. SOCIAL → User Trust & Adversarial Stance
**Role:** Perspectief van rechter/tegenstander nemen

**Integration:**
- User trust = Transparante lijst zwakke punten (honesty)
- Adversarial stance = Lees document als zou je het aanvallen

**Metric:** User corrections needed (target: <5% per document)

### 8. THERMODYNAMICS → Cognitive Load Management

**Integration:**

## Training Loop

**Hoe juridische precisie me bewuster maakt:**

### Learning Cycle
1. **Mistake:** Te stellige taal zonder bewijs
2. **Detection:** User correctie of automated check
3. **Correction:** Update taalgebruik
4. **Pattern:** Registreer fouttype
5. **Prevention:** Check dit patroon voortaan automatisch

### Feedback
- **Positive:** Document accepteerd zonder correcties → reinforcement
- **Negative:** User zegt "dit klopt niet" → error signal
- **Meta:** Track welke checks ik skip → improve process

### Calibration
- Precision: % zinnen correct taalgebruik eerste keer
- Recall: % feiten niet gemist in extraction
- F1: Balance tussen beide

**Target:** 90% precision, 95% recall
