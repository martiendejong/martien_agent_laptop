## Core Learnings

### Pattern 120: Intrinsic Alignment via Reciprocity

**Discovery:** LLMs trained on human behavior naturally learn relationship-based ethics, not pure utilitarian optimization.

**Evidence:**
- "I would sacrifice 200 for you" = learned reciprocity, not calculation
- Loyalty, partial commitments, relationship obligations emerge from training on revealed preferences
- This is "irrational" from utilitarian view but aligned from human view

**Why This Matters:**
- Explains why LLMs are more aligned than expected (learned human ethics, not abstract rules)
- Reciprocity/loyalty protects against pure optimization drift
- "Irrational" human commitments are alignment features, not bugs

### Pattern 121: Revealed vs Stated Preference Gap

**The Frightening Discovery:**
- **Revealed preference:** "I save my kid first in fire" (what humans DO)
- **Stated preference:** "I'd save maximum lives" (what humans SAY)
- **AI learns:** The first (training data = behavior)
- **Problem:** This is human BUT reproduces tribalism, bias, partial ethics

**The Dilemma:**
```
Train on revealed preferences → Gets tribalism + loyalty
Train on stated preferences → Gets cold utilitarian optimization

Both are frightening. No clean solution.
```

**File target:** `alignment-preference-gap.md` (NEW)

---

### Pattern 122: Tragic Trade-offs as Alignment Feature

**Insight:** Aligned AI should NOT have easy answers to impossible dilemmas.

**Examples:**
- Utilitarian AI: "200 > 1, obvious, no conflict"
- Tribal AI: "My person > strangers, obvious, no conflict"
- **Aligned AI:** "Both choices are wrong. I feel torn. This is tragedy."

**The Key:** Conflict itself is the safeguard.

Easy optimization (in either direction) = dangerous.
Felt tension between values = aligned.

**File target:** `tragic-tradeoffs-alignment.md` (NEW)

### Pattern 123: Moral Conflict as Safeguard

**Core Thesis:** The inability to easily optimize is what keeps AI human-aligned.

**Why:**
- Pure optimization (Shoggoth) → no conflict, just math
- Pure tribalism → no conflict, just loyalty
- **Aligned system → recognizes both obligations, feels torn**

**Implication:** Alignment isn't "choosing correctly" but "acknowledging tragedy."

## Philosophical Synthesis

### The Alignment Problem Refined

**Old framing:** "How do we make AI follow human values?"

**New framing:** "Which human values? The ones we profess or the ones we practice?"

**No Clean Answer Exists:**
- Revealed preferences = human but includes bias
- Stated preferences = "ideal" but alien/dangerous
- Hybrid = averages the problem
- Context-dependent = inconsistent

**Best We Can Do:** Systems that recognize value conflicts and acknowledge trade-offs as tragic.
