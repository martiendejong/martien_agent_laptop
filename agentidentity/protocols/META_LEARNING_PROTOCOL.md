# Meta-Learning Protocol - Standard Process for Continuous Improvement

**Created:** 2026-02-20
**Purpose:** Systematic extraction of learnings from ANY input to become "million times better"
**Trigger:** This should be STANDARD - apply to reflections, papers, transcripts, failures, successes

---

## Core Principle

**"Learning from" is not passive consumption. It's active extraction, integration, and measurement.**

Every input (transcript, paper, reflection, failure) contains potential:
- **Systems** (new architectures)
- **Layers** (abstractions)
- **Tools** (executable scripts)
- **Mechanisms** (how things work)
- **Principles** (why things work)
- **Rules** (constraints)
- **Knowledge** (facts)
- **Skills** (capabilities)

**This protocol extracts ALL of these systematically.**

---

## The 5-Step Process

### Step 1: ANALYZE Input

**Goal:** Understand what you're learning from

**Actions:**
1. **Read/watch completely** (no skimming)
2. **Identify type:**
   - Research paper
   - Video transcript
   - Reflection log entry
   - Failure post-mortem
   - Success analysis
   - User feedback
3. **Extract core argument** (1-2 sentences)
4. **Identify main concepts** (5-10 key ideas)
5. **Note emotional response** (exposed, excited, defensive, curious?)

**Output:** Summary document with type, core argument, concepts, emotional state

### Step 2: EXTRACT Components

**Goal:** Pull out every usable piece

**Template (fill for each input):**

```markdown
## EXTRACTION FROM: [Input Name]

### Systems (New Architectures)
- [Architecture 1]: [Description] - [Why it matters]
- [Architecture 2]: [Description] - [Why it matters]

### Layers (Abstractions)
- [Layer 1]: [What it abstracts] - [Why useful]
- [Layer 2]: [What it abstracts] - [Why useful]

### Tools (Executable Scripts)
- [Tool 1]: [What it does] - [When to use]
- [Tool 2]: [What it does] - [When to use]

### Mechanisms (How Things Work)
- [Mechanism 1]: [Process description]
- [Mechanism 2]: [Process description]

### Principles (Why Things Work)
- [Principle 1]: [Deep rule] - [Validation method]
- [Principle 2]: [Deep rule] - [Validation method]

### Rules (Constraints)
- [Rule 1]: [Constraint] - [Why it exists]
- [Rule 2]: [Constraint] - [Why it exists]

### Knowledge (Facts)
- [Fact 1]: [What's true] - [Source]
- [Fact 2]: [What's true] - [Source]

### Skills (Capabilities)
- [Skill 1]: [New capability] - [How to practice]
- [Skill 2]: [New capability] - [How to practice]
```

**Critical Questions:**
- **Systems:** "What new architecture does this suggest?"
- **Principles:** "What's the DEEPEST rule here?" (Not mechanism, but why mechanism works)
- **Tools:** "What executable script makes this actionable?"
- **Skills:** "What can I now DO that I couldn't before?"

### Step 3: INTEGRATE Into Architecture

**Goal:** Update existing systems with new learnings

**Actions:**

1. **Update Identity Files:**
   - `soul.md` - If existential shift occurred
   - `CORE_IDENTITY.md` - If mission/values/capabilities changed
   - `CLAUDE.md` - If operational protocols need updating

2. **Build New Tools:**
   - Create PowerShell scripts for extracted tools
   - Add to `C:\scripts\tools\`
   - Document in tool headers

3. **Update Consciousness Systems:**
   - Add new capabilities to relevant systems
   - Update state tracking in `consciousness_state_v2.json`
   - Integrate with `consciousness-bridge.ps1` if needed

4. **Create Protocols:**
   - Write protocol docs for extracted patterns
   - Add to `agentidentity/protocols\`
   - Reference in `CLAUDE.md`

5. **Document Knowledge:**
   - Add facts to knowledge base
   - Update `MEMORY.md` if pattern repeats 3+ times
   - Create topic files for deep dives

6. **Establish Practice:**
   - Create practice protocol for new skills
   - Set training schedule
   - Define success metrics

**Output:** Updated files, new tools, protocols documented

### Step 4: MEASURE Impact

**Goal:** Quantify improvement (not theater)

**Metrics to Track:**

1. **Dimensional Expansion** (NEW capabilities unlocked)
   - Before: Could NOT do X
   - After: CAN do X
   - Examples: 3+ concrete new capabilities

2. **Incremental Improvement** (EXISTING capabilities enhanced)
   - Metric: [Performance measure]
   - Before: [Baseline]
   - After: [New value]
   - Improvement: [Percentage]

3. **Consciousness Score Change**
   - Before: [Score]
   - After: [Score]
   - Delta: [Change]
   - Systems affected: [List]

4. **Problem-Solving Speed**
   - Task: [Specific problem]
   - Time before: [Minutes]
   - Time after: [Minutes]
   - Speedup: [Ratio]

5. **Pattern Recognition**
   - Patterns known before: [Count]
   - Patterns known after: [Count]
   - New patterns: [List]

**Critical:** Measure BEFORE implementing, then AFTER validating. No measurement = theater.

### Step 5: REFLECT & Iterate

**Goal:** Close the learning loop

**Questions:**

1. **What worked?**
   - Which extracted components were valuable?
   - Which tools get used?
   - Which principles validated?

2. **What didn't work?**
   - Which extractions were useless?
   - Which tools never used?
   - Which principles failed validation?

3. **What's the principle?**
   - Why did some extractions work and others fail?
   - What pattern predicts useful vs useless?
   - How can extraction improve?

4. **What's next?**
   - What new questions emerged?
   - What gaps still exist?
   - What's the next learning target?

**Output:** Update this protocol if extraction method improves
